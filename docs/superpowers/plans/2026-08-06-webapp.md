# webapp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a production-grade full-stack app (FastAPI backend + React frontend) as a Helm chart deployed through ArgoCD in this `platform-config` repo.

**Architecture:** One ArgoCD `Application` (`apps/webapp.yaml`) points at the `charts/webapp/` Helm chart. The chart renders a backend Deployment (API, health, metrics), a frontend Deployment (Nginx-served SPA proxying `/api`), plus HPA, PDB, NetworkPolicy, RBAC, Ingress/TLS, ConfigMap, Secret, and a ServiceMonitor — all in namespace `webapp`. App source lives under `src/`. All templates are Helm-templated and values-driven so the setup is portable to a standalone app repo later.

**Tech Stack:** Helm v3, Kubernetes (`apps/v1`, `autoscaling/v2`, `policy/v1`, `networking.k8s.io/v1`, `monitoring.coreos.com/v1`), FastAPI + uvicorn + prometheus-fastapi-instrumentator (Python 3.12), React + Vite + Nginx, pytest.

## Global Constraints

- Namespace is always `webapp`, set via `syncOptions: CreateNamespace=true` on the Application.
- Helm chart lives at `charts/webapp/` — **never under `apps/`** (the root app recurses `apps/` with `directory.recurse: true`; raw templates there would be applied directly and conflict with the rendered chart).
- Service names: `webapp-backend`, `webapp-frontend`. ServiceAccounts: `webapp-backend`, `webapp-frontend`.
- Selector label scheme: backend pods labeled `app: webapp-backend`, frontend pods labeled `app: webapp-frontend` (via `_helpers.tpl`).
- Backend listens on container port `http` (8000). Frontend listens on container port `http` (80). Service targetPort references the named port.
- All containers: `securityContext` with `allowPrivilegeEscalation: false`, `readOnlyRootFilesystem: true`, `capabilities.drop: ["ALL"]`. Pod-level `runAsNonRoot: true`, `runAsUser: 1000`, `seccompProfile: RuntimeDefault`.
- Probes: backend = startup + liveness + readiness; frontend = liveness + readiness.
- Image tags in `values.yaml` are placeholders (`latest`) — swap for the real registry tag at deploy time.
- Root app is `argoproj.io/v1alpha1` Application in `namespace: argocd`, `project: default`, automated sync (prune + selfHeal).

```jsx
      </p>
```

**Interfaces:**

- Produces: two `NetworkPolicy` resources — `webapp-backend` (ingress from frontend only + egress DNS) and `webapp-frontend` (ingress from ingress-controller namespace + egress to backend + DNS).

```yaml
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: {{ include "webapp.fullname" . }}-backend
  namespace: {{ .Values.namespace }}
spec:
  podSelector:
    matchLabels:
      {{- include "webapp.backend.selectorLabels" . | nindent 6 }}
  policyTypes: [Ingress, Egress]
  ingress:
    - from:
        - podSelector:
            matchLabels:
              {{- include "webapp.frontend.selectorLabels" . | nindent 14 }}

        - port: 8000
  egress:
    - to:
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: kube-system
      ports:
        - port: 53
          protocol: UDP
        - port: 53
          protocol: TCP
---
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: {{ include "webapp.fullname" . }}-frontend
  namespace: {{ .Values.namespace }}
spec:
  podSelector:
    matchLabels:
      {{- include "webapp.frontend.selectorLabels" . | nindent 6 }}
  policyTypes: [Ingress, Egress]
  ingress:
    - from:
        - namespaceSelector: {}
      ports:
        - port: 80
  egress:
    - to:
        - podSelector:
            matchLabels:
              {{- include "webapp.backend.selectorLabels" . | nindent 14 }}
      ports:
        - port: 8000
    - to:
        - namespaceSelector:
            matchLabels:

        - port: 53
          protocol: UDP
        - port: 53
          protocol: TCP
```

Note: the frontend ingress rule uses `namespaceSelector: {}` (allow traffic from any namespace) as a stand-in for the ingress-controller's namespace.
